## 🧑‍💻 Sobre mim

<img align="right" alt="coding" width="340" src="https://user-images.githubusercontent.com/55389276/140866485-8fb1c876-9a8f-4d6a-98dc-08c4981eaf70.gif">

Desenvolvedor **Full-Stack** e **Analista de Geotecnologia** na Usina Ester. Construo produtos que saem do código e vão para o campo: IA, dados geoespaciais e sistemas web e mobile para o agronegócio.

- 🛰️ Modelo de IA para detectar plantas daninhas em imagens de drone, com **até 30% de economia** na operação
- 🌾 Criador do **[CanaLyze](https://canalyze.com.br)**, plataforma com IA para o setor sucroenergético
- 📱 Apps mobile **offline-first**, que sincronizam os dados quando há internet
- 🎓 Cursando Ciência da Computação
- 🎯 Objetivo: escalar tecnologia no agro
